# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please **do not** open a public GitHub issue. Instead, report it privately via [GitHub Security Advisories](https://github.com/KrushanPatel/auth-service/security/advisories/new) or by contacting the maintainer directly.

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce (or a proof of concept)
- Any suggested mitigation, if you have one

We'll acknowledge your report and work with you on a fix before any public disclosure.

## Supported Versions

This project does not yet follow semantic versioning or maintain release branches — only the `main` branch is supported.
